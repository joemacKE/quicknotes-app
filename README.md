# QuickNotes

QuickNotes is a simple note-taking web application built with HTML, CSS, and JavaScript. It allows users to create notes, organize them into Personal, Work, and Study categories, search through their notes, delete individual notes, and keep their notes saved in the browser using localStorage.

## Features

- Add notes with a text description.
- Organize notes into Personal, Work, and Study categories.
- Display the date and time when each note was created.
- Delete individual notes.
- Search notes as you type.
- Case-insensitive note searching.
- Validate notes to prevent empty notes.
- Limit notes to 200 characters.
- Display the total number of notes.
- Save notes to localStorage.
- Load saved notes when the page is refreshed.
- Responsive design for smaller screens.
- Category-specific visual styles.
